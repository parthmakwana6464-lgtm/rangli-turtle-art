# Rangoli

A vibrant generative-art project that creates colorful, mandala-like floral patterns using Python's built-in `turtle` and `colorsys` modules.

The artwork features smooth, rainbow-gradient geometric petals drawn on a sleek black background with optimized animation speed.

## Requirements

* Python 3 (No external libraries or pip installations required; `turtle` and `colorsys` are part of the standard library).

## Run

Make sure your script file (e.g., `rangoli.py`) is saved in your working directory.

Run the program from your terminal:

```bash
python rangoli.py

```

On Windows, you can also use:

```bash
py rangoli.py

```

## Features

* **Zero Dependencies:** Uses only standard Python modules.
* **Smooth Animation:** Utilizes `tracer(10)` and high drawing speed for instant rendering.
* **Dynamic Color Gradients:** Automatically cycles through HSV color spaces for a glowing effect.

Enjoy creating and customizing your digital rangoli art! 🎨
